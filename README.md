# Totem Alarm — legal

Public hosting for the Totem Alarm privacy policy, kept in its own repository
so the app source can stay private while GitHub Pages (free only on public
repos) serves the policy at a stable URL.

Published at <https://jtallet10-jpg.github.io/totem-privacy/>

`index.html` mirrors `docs/privacy-policy.html` in the app repo and the
in-app Privacy screen. Change all three together.
